# Mother City

A small, original, browser-playable mobile game prototype set in a fictional Cape Town neighbourhood. It is a self-contained HTML canvas experience with no build step or third-party runtime dependencies.

## Play

Open `index.html` in a modern browser. On desktop, move with **WASD** or the **arrow keys** and use **E** or the **Talk** button near a character or location. On touchscreens, use the directional pad and the **Talk** button.

## Prototype loop

- Explore the Salt River inspired street grid and meet local characters.
- Follow a mystery about missing community garden title deeds.
- Choose how Thabo builds trust and gathers information. Earn respect along the way.
- Visit the Harbour Street Gym or Sea Point Promenade for optional free-time activities.
- Meet the courier and radio host for additional story leads and neighbourhood flavour.

All neighbourhood names and events are fictionalized. The visual world is drawn with the Canvas API; no external game assets are used.
